# Kävelymatto- ja askelseuranta (Walking Pad & Step Tracker)

Sovelluksen tarkoitus on seurata päivittäistä askeltavoitetta, sekä kuinka se on saavutettu. 
Sovelluksen avulla käyttäjä voi analysoida itse omaa askeltahtiaan eri nopeuksilla ja seurata tavoitteiden saavuttamista. 

## Keskeiset toiminnot

- Käyttäjätunnuksen luominen ja sisään kirjautuminen.
- Käyttäjä pystyy luomaan uuden kävelysession [Otsikko, Päivämäärä, Askeleet, Kesto(min), Kuvaus].
- Käyttäjä pystyy katsomaan aikaisempia sessioitaan.
- Käyttäjä pystyy muokkaamaan ja poistamaan aikasempia sessioitaan.
- Käyttäjä näkee listan kaikista aikaisemmista sessioista ja pystyy aukaisemaan tästä uuden näkymän jossa tarkemmat tiedot sessiosta.
- Käyttäjä pystyy hakemaan sessioita.
- Käyttäjä pystyy rajaamaan näkyviä sessioita luokitteluiden mukaan.
- Käyttäjän sivulla myös näkyy kokonaisseuranta suoritetuista tavotteista.

## Luokittelu 
Session voi luokitella seuraavasti:
- Oheistekeminen: Palaveri, Ohjelmointi, Opiskelu, Median katselu, Muu
- Ajankohta: Aamu, Päivä, Ilta
- Nopeus: Hidas, Normaali, Reipas, Hölkkä, Juoksu

## Toissijainen tietokohde
Käyttäjät voivat jättää toisilleen motivoivia viestejä sessioihin.
Sessiota katsoessa voi nähdä kaikki sitä koskevat viestit.
